# Visual Production Bridge

Use this Skill in Local Codex or a Codex Cloud Work task that has a Repository checkout, Node.js, `image_gen.imagegen`, and an image inspection tool in the current session. This Skill is a request-bound Repository bridge, not platform-wide interception of ChatGPT image generation.

1. Resolve and read Current canonical Sources under `AI_PRODUCTION_PIPELINE.md` and `04_AI_Work_Environment/Source_Resolution/`. Create a task/version-specific Source Manifest v2. In Cloud Work use `source-resolution.mjs`; in Local Codex use either that validator or `Test-SourceResolution.ps1`. Stop on any FAIL.
2. For an AIDAILY Header in Cloud Work, run `cloud-work-header-bridge.mjs prepare`; in Local Codex run `New-VisualGenerationRecord.ps1`. Do not manually recreate or paraphrase canonical MUST/MUST_NOT requirements. Use profile `aidaily-header-v1` from `07_Note_Production/00_note制作・公開システム.md`; resolve `NOTE-HEADER-MASTER-v1.0` and its manifest from the Repository Visual Production asset area. Do not depend on the OneDrive copy or substitute an external file.
3. In Cloud Work use the generated `imagegen-arguments.json` as the exact native Tool arguments. In Local Codex use the existing actual-request export. Do not edit the prompt, approved title, referenced image path, dimensions or requirement IDs.
4. Pass the exact validated prompt and the exact Repository Master path to `image_gen.imagegen`. Do not add surrounding creative instructions or substitute a visually similar image. Record the current-task Tool event with `evidence_origin=current-task-cloud-work-tool-event`, event ID/time, exact arguments, Raw Asset locator/SHA/measured dimensions and Contract identity. If the environment cannot expose or persist this event, stop at `BLOCKED_PLATFORM_BOUNDARY`.
5. Run `cloud-work-header-bridge.mjs bind-runtime` in Cloud Work, or the applicable Local Codex receipt path. The receipt must use the real environment ID, return `REQUEST_BOUND`, retain `platform_enforced=false`, match the exact invocation arguments and bind the unchanged Raw Asset as `RAW_GENERATED_UNVERIFIED`. Native dimensions may differ from 1280×670 at this stage.
6. Run `cloud-work-header-bridge.mjs normalize` before inspection. It must use `repository-node-png-normalizer` v1.0.0 to create a new 1280×670 PNG by deterministic center-crop cover, fixed-point bilinear resampling and canonical RGBA8 encoding. Preserve the Raw Asset unchanged. Record input/output SHA and dimensions, crop, tool/version/method, Tool event SHA, execution event and timestamps in `header-asset-normalization/v1` Evidence.
7. Inspect the Normalized Asset, not the Raw Asset, with the available image inspection tool. Bind the inspection event to the Raw SHA, Normalization Evidence SHA/identity and Normalized SHA. Complete every mandatory requirement check and the unchanged 1280×670 dimensions check. On QA FAIL, keep both outputs outside Formal Asset status.
8. In Cloud Work record the inspection event in `cloud-work-header-asset-qa/v2`, then run `cloud-work-header-bridge.mjs complete-qa`. Only the fully bound Normalized Asset with Asset QA PASS may transition to `HUMAN_REVIEW_CANDIDATE`.
9. For a note Header, record the Human response only after the exact Normalized Candidate was presented. Bind its event ID/time, Article ID, approved display title, Raw Asset SHA, Normalization identity, Normalized Asset SHA, Visual Record SHA, Runtime Receipt SHA, actual request SHA, destination `NOTE_FINAL_REVIEW_PACKAGE`, and purpose `NOTE_HEADER_ASSET_PROMOTION`.
10. Run `cloud-work-header-bridge.mjs promote` in Cloud Work or the existing Local Codex promotion path. Cloud promotion must revalidate Raw Asset, Normalization Evidence, Normalized Asset, QA and Human Approval. Only its verified `FORMAL_HEADER_ASSET` output may enter the Final Review Package Compiler.
11. In Cloud Work use `final-review-package-compiler.mjs`; do not require PowerShell. A direct built-in output, Raw Asset, unbound resized file or Human approval without the complete Repository Bridge chain remains ineligible and must not be retroactively promoted.

If the current environment is ordinary Chat/Work without the Repository runtime, or if request binding, current-task Tool event, generated Asset bytes, inspection event or Node.js execution is unavailable, report `BLOCKED_PLATFORM_BOUNDARY`. Do not claim the Repository directly intercepted the platform tool. A Cloud Work task that satisfies the bridge contract may complete daily Header production without Local Codex.

Keep runtime records and generated binaries outside the Public Repository unless an existing responsibility Source explicitly assigns a durable destination. Never commit rejected images, private source text, credentials, or conversation transcripts.
