## 運用規則

このファイルは、Sectionレベルの優先順位、依存関係、制作・公開の現在地を示す。Timelineは事実の時系列だけを扱うため、Sectionの状態、Next、Blockerは本ファイルまたはSection制作台本を正とする。実データが生じるまで、具体的なSection行は追加しない。

| _実データ発生時に追加_ |  |  |  |  |  |  |  |

Section Statusは `Planning`、`Production`、`Review`、`Approved`、`Scheduled`、`Published/Complete`、`Update Candidate` のいずれかとする。Statusは3記事すべてと公開成果物記録に基づいて更新し、SNSの実投稿状況だけではSectionの完了を判断しない。

ロードマップ上の候補は公開または制作の承認を意味しない。順序の変更、無料／有料の役割、商品導線、自己開示を伴う企画は、必要に応じてHuman Ownerへ戻す。
