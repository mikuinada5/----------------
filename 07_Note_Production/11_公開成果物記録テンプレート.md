上記3記事欄は既定Profile用である。Section固有のHuman承認済み公開構成Profileがある場合は、そのProfileの成果物と分離境界を記録する。AI Organization Series Section 1では、S1-1だけStory＋Practiceのnote本編を `01_note本編_最終稿.md` とし、Session ArchiveはHumanが公開範囲とMembershipでの扱いを承認した場合だけ `02_Session_Archive_最終稿.md` として記録する。S1-2以降はStory、Practice、Session Archiveを独立記事／成果物として扱い、Section制作台本に記録されたcanonical path対応を使用する。未公開のSession Archive欄を公開済みとして埋めない。公開済み最終稿は、公開版と照合済みの本文だけを置き、掲載画面を見ただけで本文を推測してはならない。

`Decision Pending`または`Revision Required`では外部公開しない。差し戻しにより修正が必要な場合は、未変更のDraft・Review結果を有効なまま保持し、修正対象だけをSection制作台本の再Reviewへ戻す。

`Approved`は、Package-bound Human Final Approval / Publication ApprovalとG5自動検証がPASSした状態である。公開URL、公開日時およびG8／G9が未成立なら`Published`と記録しない。Publication Settingsが下書きへ永続化されない場合は`Not Persisted・Expected Behavior`として記録し、Transaction時にPublication Decision Summaryから再構成する。この再構成だけを再承認理由にしない。未公開状態の詳細Reviewや本文を本公開済み正本領域へ先行配置しない。

Series articleでは、当該Series Publication Profileに定義された必須所属先をPublication Decisionへ継承し、Final Review Package、G5、TransactionおよびPost-Publication Verificationで照合する。Membership Plan、無料／限定境界およびMagazineは別設定として記録する。初回Verification後にHuman QAでGapが見つかった場合、初回判定を消さず、時系列を保ったまま`Reopened`とし、現在の修正状態が確認できなければ`Unknown / Human Action required`とする。特定Series固有のMagazineを他Seriesへ自動適用しない。

## 2. 記事間リンク記録

| Link Record ID | Source Article ID | Target Article ID | Placement | Link Type / Card Type | Status | Target URL | Backfill Human Publication Approval | Backfill実施日時 / 実行経路 | PPV結果 | 最終確認日時 | Error / 再開条件 |
|---|---|---|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  | Pending / Target Published / Backfill Prepared / Backfill Failed / Recovery Required / Resolved |  |  |  | Not Started / PASS / FAIL |  |  |

各行はSource Article側の公開成果物記録へ置き、公開前のSection制作台本等から同じLink Record IDを引き継ぐ。`Pending`はリンク予定が存在する状態であり、Target URLが空欄でもリンク予定なしとは扱わない。Target未公開中はTarget URLを空欄にし、未公開URL、仮URLまたは推測URLを記録しない。Target Articleの公開成果物記録で実在URLと初回PPV PASSを確認した後だけ`Target Published`へ進める。Backfill後のリンク／カード、遷移先Article ID、Placementおよび周辺本文を再PPVし、PASSした場合だけ`Resolved`とする。失敗・未確認時は`Resolved`にせず、未完了状態と再開条件を保持する。現在のリンク状態は本記録を正とし、Timelineへ状態管理を移さない。
