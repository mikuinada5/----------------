# 全コース共通 教材制作基準

# 20_成果物間整合・情報配置基準

## 0. 本文書の位置づけ

本文書は、「フェミニンウェルネス生涯教育事業」における教材制作について、

**承認済み教育設計・上位Sourceをもとに制作される複数の教材成果物が、それぞれ固有のMissionを保ちながら、教材一式として同じ教育を矛盾なく実装・維持するための横断基準**

を定義する。

本文書は、

-   `00_教材制作システム概要・共通原則.md`
-   `01_制作AI_判断・裁量基準.md`
-   `02_教材制作・品質保証フロー.md`

を上位基準として適用する。

また、各成果物固有の制作仕様については、

-   `10_PPT制作基準.md`
-   `11_受講者配布資料制作基準.md`
-   `12_ワークシート制作基準.md`
-   `13_講師進行表制作基準.md`
-   `14_講師実施設計制作基準.md`
-   `15_講師セルフチェック制作基準.md`

を正とする。

本文書は、個別成果物の制作仕様を再定義するものではない。

------------------------------------------------------------------------

# 1. 本基準のMission

本基準のMissionは、

> **承認済み教育設計・上位Sourceをもとに制作される教材成果物について、各成果物固有のMissionと責任分離を保ちながら、必要な教育情報の欠落、不必要な重複、教育的意味の不整合、参照関係の断絶、変更時の同期漏れを防ぎ、教材一式として同じ教育を一貫して実装・維持できる状態をつくること**

である。

成果物間整合とは、

**すべての成果物を同じ文章・同じ情報量・同じ構成にすることではない。**

各成果物が異なるMissionを担いながら、

**教材一式として一つの承認済み教育を成立させていること**

を意味する。

------------------------------------------------------------------------

# 2. 本基準が扱う範囲

本文書は、主として以下を扱う。

-   教材一式の共通構造
-   教育情報の成果物間配置
-   各成果物の実装責任
-   必要情報の配置漏れ
-   同一教育情報の重複
-   成果物間の教育的整合
-   成果物間の対応関係
-   成果物間参照
-   他Session参照
-   変更時の影響確認
-   成果物間同期
-   横断QA
-   受講者配布資料とワークシートの統合／分冊に関する共通方針

------------------------------------------------------------------------

# 3. 教育設計と教材制作を分離する

教育設計は、

> **何を、なぜ、どこまで、どのような教育構造で学ぶか**

を決定する。

教材制作は、

> **承認済み教育設計・上位Sourceで確定した教育を、実際に使用できる教材成果物へ実装すること**

を担う。

したがって、本文書は、

-   新しい教育内容
-   新しい学習目標
-   新しい知識深度
-   新しい問い
-   新しいワーク
-   新しい必須／任意
-   新しい教育順序
-   新しい評価条件
-   新しい教育上のSession間導線

を決定しない。

成果物間整合を理由として、制作AIが教育そのものを再設計してはならない。

------------------------------------------------------------------------

# 4. 教育内容・教育仕様の正

教育内容・教育仕様については、

> **当該事項を正式に決定している承認済み教育設計・上位Sourceを正とする。**

教材制作時は、対象Sessionの承認済み教育設計を中心に確認し、当該事項の本籍が上位Sourceにある場合、または必要な判断がSession教育設計のみでは確定できない場合は、必要な上位Sourceへ遡って確認する。

教材成果物間で教育的意味の不整合が発生した場合、

**他の教材成果物を正として修正してはならない。**

例えば、

-   PPT
-   受講者配布資料
-   ワークシート
-   講師進行表
-   講師実施設計
-   講師セルフチェック

の記載が食い違っている場合、

多数決、情報量、制作順序、ファイル更新日時等によって正解を決定しない。

当該事項を正式に決定している承認済み教育設計・上位Sourceへ戻り、正しい教育仕様を確認する。

------------------------------------------------------------------------

# 5. 教材成果物を別成果物の派生版として扱わない

各成果物は、

**承認済み教育設計・必要な上位Source、教材一式の共通構造、該当成果物制作基準**

を基礎として制作する。

先に制作された成果物を、後続成果物の唯一の正式な参照元として扱わない。

例えば、

-   PPTをコピーして受講者配布資料を作る
-   講師実施設計を要約して講師進行表を作る
-   講師進行表から講師セルフチェックを生成する

ことを標準制作方法としない。

他成果物は、横断照合・参照・対応確認には使用できる。

ただし、

> **一つの成果物に存在することだけを理由として、新しい教育責任を他成果物へ生成してはならない。**

------------------------------------------------------------------------

# 6. 教材一式の共通構造

個別成果物を制作する前に、

**教材一式の共通構造**

を整理する。

共通構造は、

> **承認済み教育設計・上位Source上の重要情報を、教材一式としてどの成果物が、どのような責任で実装するかを整理するための内部設計**

である。

共通構造は教育内容そのものを決定する資料ではない。

承認済み教育設計・上位Sourceと共通構造が矛盾する場合は、

**当該事項を正式に決定している承認済み教育設計・上位Sourceを正とし、共通構造側を修正する。**

------------------------------------------------------------------------

# 7. 共通構造で確認する情報

共通構造では、案件に応じて、制作・横断QAに必要な範囲で以下を整理する。

-   Session／Block／Section構造
-   教育順序
-   必須教育コア
-   問い
-   ワーク
-   知識深度
-   非変更領域
-   目安時間
-   必須／任意
-   各成果物への情報配置
-   各成果物の実装責任
-   成果物間の対応関係
-   成果物間参照
-   その他、教材一式の整合確認に必要な事項

教育設計・上位Sourceの全文を共通構造へ転記する必要はない。

------------------------------------------------------------------------

# 8. 共通構造は教育設計のコピーではない

共通構造の目的は、

**教育設計・上位Sourceを別形式で複製することではない。**

教育設計・上位Source上の情報について、

-   教材として実装する必要があるか
-   どの成果物が担うか
-   複数成果物で担う必要があるか
-   どの成果物と対応するか
-   変更時にどこへ影響するか

を整理するために使用する。

教育設計・上位Sourceに存在するすべての文章について、教材成果物上の配置先を機械的に設けることを要求しない。

------------------------------------------------------------------------

# 9. 共通構造の形式

共通構造に、固定された表形式・列構成を一律に要求しない。

案件に応じて、

-   表
-   構造化リスト
-   対応マップ
-   その他の内部整理形式

を使用できる。

重要なのは形式ではなく、

> **教材実装が必要な教育情報について、各成果物の実装責任および必要な対応関係を追跡できること**

である。

------------------------------------------------------------------------

# 10. 共通構造の保存

共通構造は、制作AIが教材一式を一貫して制作するための内部中間物として使用する。

原則として、

**正式教材成果物または教育内容を決定する恒久的な正本として保存することを必須としない。**

案件の複雑性、変更影響確認、制作継続等のために有用な場合は、内部作業資料として保存してよい。

保存した場合も、当該事項を正式に決定する承認済み教育設計・上位Sourceより上位の判断根拠とはならない。

------------------------------------------------------------------------

# 11. 情報配置の基本原則

教育情報は、

**各成果物のMissionに応じて配置する。**

制作AIは、

-   重要だから
-   念のため
-   他成果物にもあるから
-   詳しい方が親切だから
-   専門的に重要だから

という理由だけで、同一情報を複数成果物へ機械的に複製しない。

一方、

**他成果物に情報が存在することだけを理由として、当該成果物のMission上必要な情報を省略してはならない。**

------------------------------------------------------------------------

# 12. 教材として実装・担保すべき情報

教材として実装・担保すべき情報は、

> **承認済み教育設計・上位Sourceおよび各成果物Missionに照らして、教材一式として実装・担保する必要があると確定できる情報**

とする。

制作AIは、

-   重要そうだから
-   あった方がよさそうだから
-   念のため必要だから

という理由だけで、新しい実装責任を生成しない。

既存Sourceと各成果物Missionから実装の必要性を確定できない場合は、制作AIが独自に必須化せず、`01_制作AI_判断・裁量基準.md`に従って判断する。

------------------------------------------------------------------------

# 13. 必要情報の配置漏れを防ぐ

必要情報の欠落は、

**完成した成果物同士だけを比較して判定しない。**

承認済み教育設計・必要な上位Sourceおよび教材一式の共通構造を起点として確認する。

教材として実装・担保すべき教育情報について、必要な成果物上に適切な実装責任が存在しない場合を、配置漏れとして扱う。

ただし、

教育設計・上位Sourceに存在するすべての設計情報を、教材成果物へ明示的な文章として転記する必要はない。

------------------------------------------------------------------------

# 14. 明示記載と教育上の担保を区別する

教育情報が教材一式で担保されていることは、

**必ずしも、その情報が成果物上へ同じ文章として明示されていることを意味しない。**

例えば、

-   受講者へ直接表示する必要がある情報
-   講師が実施判断として理解する必要がある情報
-   本番中に瞬時に確認する必要がある情報
-   ワークの構造として実装される情報
-   セルフチェック項目として実施後に確認する情報

では、同じ教育情報であっても実装方法が異なる。

制作AIは、

> **その教育責任が、教材一式として適切に成立しているか**

を確認する。

------------------------------------------------------------------------

# 15. 同一教育情報の重複

同一教育情報が複数成果物に存在することを、一律に禁止しない。

複数成果物に必要な場合は、

**各成果物のMissionに必要な範囲・深度・表現で保持する。**

例えば、同じ実施条件について、

-   講師実施設計では、背景・意図・実施判断まで理解する
-   講師進行表では、本番中に必要な条件を瞬時に確認する

等、成果物ごとに異なる実装が成立する。

------------------------------------------------------------------------

# 16. 重複には成果物固有の理由を必要とする

同一情報を複数成果物へ配置する場合、

制作AIは、

> **なぜその成果物にもその情報が必要なのか**

を、当該成果物のMissionから説明可能でなければならない。

他成果物に存在すること、重要な情報であること、念のため残した方が安全であることのみを理由として複製しない。

同一情報の重複が確認された場合、

-   各成果物に存在する必要性
-   必要な情報深度
-   表現方法
-   役割分担

を確認する。

------------------------------------------------------------------------

# 17. 成果物間で一致すべきもの

成果物間では、少なくとも以下について教育的意味が矛盾しないことを確認する。

-   必須教育コア
-   必須／任意
-   教育上意味を持つ順序
-   問いの教育機能
-   ワークの教育機能
-   知識深度
-   非変更領域
-   評価／非評価
-   教育上の実施条件
-   用語の意味
-   その他、教育的意味を左右する事項

成果物によって、これらの意味を独自に変更してはならない。

------------------------------------------------------------------------

# 18. 成果物間で異なってよいもの

成果物間で、以下が同一であることを要求しない。

-   文章量
-   表現方法
-   情報の詳しさ
-   ページ数
-   スライド数
-   レイアウト
-   視覚表現
-   図解の有無
-   情報の提示方法
-   その他、各成果物Missionに応じた制作上の実装

ただし、実装差によって教育的意味を変更してはならない。

------------------------------------------------------------------------

# 19. 成果物間整合は「同じ文章か」では判定しない

成果物間整合では、

**同じ文章が書かれているかではなく、同じ承認済み教育を向いているか**

を確認する。

例えば、

-   任意が必須化されていないか
-   重要度が変化していないか
-   具体例が模範回答化されていないか
-   知識深度が勝手に拡張されていないか
-   同じ問いが別の思考を要求するものへ変質していないか
-   成果物固有の役割分担が崩れていないか

等を確認する。

------------------------------------------------------------------------

# 20. 成果物間に不整合が見つかった場合

成果物間に教育的意味の不整合が確認された場合は、

1.  当該情報を決定している承認済み教育設計・上位Sourceへ戻る
2.  正しい教育仕様を確認する
3.  教材一式の共通構造に誤りがある場合は修正する
4.  影響する成果物を特定する
5.  各成果物のMissionに基づいて必要な修正を行う
6.  必要な範囲で横断再確認する

という順で対応する。

他成果物を直接コピーして修正しない。

------------------------------------------------------------------------

# 21. 上位Sourceでも正解を確定できない場合

承認済み教育設計・上位基準を確認しても、

-   正しい教育仕様を確定できない
-   必須／任意を判断できない
-   知識深度を判断できない
-   問い・ワークの教育機能を確定できない
-   上位Source同士が矛盾している
-   新しい教育判断が必要である

等の場合、

制作AIは独自に整合させない。

`01_制作AI_判断・裁量基準.md`

に従い、🟡理由付き提案・確認または🔴差し戻しを行う。

------------------------------------------------------------------------

# 22. 成果物間の対応関係

教材一式では、必要に応じて、

-   Session
-   Block
-   Section
-   Slide
-   ワーク
-   受講者配布資料
-   講師進行表
-   講師実施設計
-   講師セルフチェック
-   その他関連成果物

の対応関係を追跡できる状態にする。

すべての成果物へ同一の番号体系を要求するものではない。

重要なのは、

> **必要な対応関係が正しく接続され、実際に追跡できること**

である。

------------------------------------------------------------------------

# 23. 成果物間参照

成果物間で、

-   Slide番号
-   ページ
-   ワーク名称
-   ワーク番号
-   Block／Section
-   他成果物名称
-   その他の参照情報

を使用する場合、

現在の対象教材における実際の対応関係を確認して設定する。

過去Version、記憶、推測、旧教材の対応関係のみを根拠として設定しない。

------------------------------------------------------------------------

# 24. 参照情報が変更された場合

成果物間参照・対応番号・名称等が変更された場合、

**その情報を参照している成果物・箇所を特定し、必要な同期を行う。**

例えば、PPTの構成変更によってSlide番号が変化した場合、

教育内容そのものに変更がなくても、対応Slide番号を持つ講師進行表等には同期が必要となる場合がある。

この場合、

**参照関係に影響する箇所のみを必要に応じて更新し、影響しない教育内容を不必要に変更しない。**

番号をどのように付与・表示・識別するかという具体的管理要件は、`21_出典・教材識別・Version管理基準.md`を正とする。

付与された番号・名称等を用いた成果物間対応と、変更時にどこへ同期するかは本文書で扱う。

------------------------------------------------------------------------

# 25. 他Session参照

他Sessionへの参照は、

**他Sessionの教育内容を本Sessionへ取り込むために使用しない。**

承認済み教育設計・上位Sourceに、他Sessionとの教育上の関係・参照・学習上の位置づけが存在する場合に、その関係を必要な成果物へ実装する。

他Sessionに詳細知識の正式な本籍がある場合でも、本Sessionの知識深度を超えて詳細を複製しない。

------------------------------------------------------------------------

# 26. 制作AIは新しいSession間導線を作らない

承認済み教育設計・上位Sourceに根拠がない場合、

制作AIは、

-   関連しているから
-   後で学ぶと便利だから
-   詳細を知った方がよいから
-   学習上親切だから

等を理由として、

**新しい他Session参照・学習導線・教育上の位置づけを追加してはならない。**

制作過程で有用な改善可能性を発見した場合は、現行教材へ実装せず、01に従って後続検討事項として分離して提案できる。

承認されるまで、現行教材の正式仕様として扱わない。

------------------------------------------------------------------------

# 27. 変更影響は成果物単位ではなく情報単位で確認する

教材成果物へ変更が発生した場合、

**変更されたファイル全体を理由として、教材一式すべてを機械的に再制作しない。**

変更された、

-   教育情報
-   実装情報
-   対応関係
-   参照情報
-   構造

等のうち、

**何が変わったのか**

を確認し、その情報に基づいて影響範囲を判断する。

------------------------------------------------------------------------

# 28. 成果物側で変更が発生した場合

一つの成果物に変更が発生した場合、

その成果物を起点として他成果物へ直接変更を派生させない。

必要に応じて、

1.  変更箇所が対応する承認済み教育設計・上位Sourceを確認する
2.  共通構造上の対応関係を確認する
3.  何の情報が変更されたか特定する
4.  影響する成果物を特定する
5.  各成果物をそれぞれのMissionに基づいて確認・修正する
6.  必要な範囲で横断再確認する

という順で対応する。

------------------------------------------------------------------------

# 29. 教育設計・上位Source側で変更が発生した場合

承認済み教育設計・上位Sourceが正式に変更された場合は、

1.  変更された教育情報を特定する
2.  教材一式の共通構造への影響を確認する
3.  必要に応じて共通構造を更新する
4.  影響する成果物を特定する
5.  各成果物を該当成果物基準に従って更新する
6.  必要な範囲で成果物間横断確認を行う

という順で対応する。

上位Sourceの変更を理由として、影響しない成果物・情報まで機械的に変更しない。

------------------------------------------------------------------------

# 30. 制作上の変更と教育上の変更を区別する

以下のような制作上の変更は、

-   レイアウト調整
-   余白調整
-   改ページ
-   スライド分割
-   文字量調整
-   視線誘導改善
-   その他、教育的意味を変更しない実装変更

その変更が共通構造・成果物間対応・参照関係等へ影響しない場合、

当該成果物内の確認で完了できる。

ただし、例えばスライド分割によってSlide番号が変更される等、

**教育内容そのものに変更がなくても成果物間対応へ影響する場合は、影響する参照情報を同期する。**

------------------------------------------------------------------------

# 31. 不必要な変更を行わない

成果物間同期を理由として、

**影響しない教育内容・表現・成果物を不必要に変更しない。**

変更影響は、

> **「どのファイルを変更したか」ではなく、「どの情報・対応関係を変更したか」**

を基準として判定する。

同期の過程で、

-   表現改善
-   情報追加
-   新しい例
-   新しい教育導線
-   新しい知識
-   新しいワーク

等を無関係に追加しない。

------------------------------------------------------------------------

# 32. 受講者配布資料とワークシートの統合／分冊

受講者配布資料とワークシートを、

-   統合する
-   分冊する

という物理的構成方針は、

**原則としてCourse単位で統一する。**

同一Course内で、Sessionごとに制作AIが独自に統合／分冊を変更しない。

全コース共通の正式方針が別途決定されている場合は、その方針を優先する。

対象Courseに統合／分冊の正式方針が存在しない場合、

**Session制作AIが独自に方針を確定しない。**

Courseとして最初に適用する統一方針を確認・決定したうえで、その後のSessionも同方針に従う。

------------------------------------------------------------------------

# 33. 統合／分冊によってMissionを変更しない

受講者配布資料とワークシートを物理的に統合する場合でも、

-   受講者配布資料のMission
-   ワークシートのMission

は分離して保持する。

統合によって、

-   配布資料を記入しなければ完成しない教材にする
-   ワークシートを復習用解説資料へ変える
-   教育コアと受講者自身の回答を混同する

等、それぞれの成果物Missionを変質させてはならない。

具体的な媒体固有要件は11・12を正とする。

------------------------------------------------------------------------

# 34. 横断QAの基本

成果物別セルフレビュー後、

教材一式について横断QAを行う。

横断QAでは、

> **各成果物が単体で成立しているかだけでなく、教材一式として一つの承認済み教育を正しく実装しているか**

を確認する。

横断QAは、

-   教育的整合
-   情報配置
-   対応・参照
-   変更同期

の観点から行う。

------------------------------------------------------------------------

# 35. 横断QA｜教育的整合

教育的整合では、案件に応じて以下を確認する。

-   教育コアの意味が一致している
-   必須／任意が矛盾していない
-   問いの教育機能が変質していない
-   ワークの教育機能が変質していない
-   知識深度が勝手に拡張・縮小されていない
-   教育上意味を持つ順序が保持されている
-   非変更領域が保持されている
-   評価／非評価が変化していない
-   実施条件が矛盾していない
-   用語の意味が矛盾していない
-   成果物ごとの表現差によって教育的意味が変わっていない

------------------------------------------------------------------------

# 36. 横断QA｜情報配置

情報配置では、案件に応じて以下を確認する。

-   教材として担保すべき必要情報が教材一式から欠落していない
-   必要な成果物に必要情報が配置されている
-   各成果物が固有Missionを果たしている
-   他成果物の責任を不必要に抱え込んでいない
-   同一情報の重複に成果物固有の理由がある
-   必要な重複が、適切な深度・表現で実装されている
-   他成果物に情報があることを理由として、必要情報を省略していない

------------------------------------------------------------------------

# 37. 横断QA｜対応・参照

対応・参照では、案件に応じて以下を確認する。

-   Session／Block／Sectionの対応
-   Slideの対応
-   ワーク名称・番号
-   配布資料との対応
-   講師資料との対応
-   成果物間参照
-   他Session参照
-   用語・名称
-   その他、教材使用時に必要なリンク関係

番号体系そのものが同一であることではなく、

**必要な対応関係が正しく追跡できること**

を確認する。

------------------------------------------------------------------------

# 38. 横断QA｜変更同期

変更同期では、案件に応じて以下を確認する。

-   何の情報が変更されたか特定されている
-   変更影響範囲が確認されている
-   影響する成果物が更新されている
-   古い情報・参照関係が残っていない
-   必要な再確認が行われている
-   影響しない成果物を不必要に変更していない
-   変更によって新しい不整合が発生していない

------------------------------------------------------------------------

# 39. 出典・Primary Sourcesとの境界

成果物間横断確認において、

-   根拠関係が成果物間で矛盾していないか
-   必要な根拠との対応が切れていないか

等を確認する場合がある。

ただし、

-   出典表記
-   Primary Sources管理
-   第三者制作物管理
-   根拠情報の具体的表示方法
-   出典の配置要件

等の具体的管理基準は、

`21_出典・教材識別・Version管理基準.md`

を正とする。

------------------------------------------------------------------------

# 40. 教材識別・Version管理との境界

本文書では、

**変更によってどの成果物・情報・参照関係へ影響するか**

を扱う。

一方、

-   Course識別
-   Program識別
-   Session識別
-   成果物種別
-   Version
-   Status
-   対応教育設計Version
-   ファイル名
-   ページ番号・スライド番号等の具体的な付与・表示・識別方法
-   変更履歴

等の具体的管理要件は、

`21_出典・教材識別・Version管理基準.md`

を正とする。

番号・識別情報をどう付与・表示・管理するかは21、
その番号・識別情報を用いた成果物間対応と変更時の同期範囲は20として責任を分離する。

Version変更によって成果物間同期が必要となった場合、

-   Versionをどう管理するか → 21
-   変更内容がどこへ影響し、何を同期するか → 20

として責任を分離する。

------------------------------------------------------------------------

# 41. 各成果物制作基準との境界

本文書は、

**成果物間の関係・配置・整合・同期**

を定める。

各成果物そのものについて、

-   何を表示するか
-   どの程度詳しくするか
-   どのような構造で制作するか
-   どのようなレイアウトとするか
-   どのような実ファイル品質を求めるか

等の媒体固有要件は、10〜15の各成果物制作基準を正とする。

本文書は各成果物制作基準のMissionを侵食しない。

------------------------------------------------------------------------

# 42. 制作AIの判断・裁量との境界

成果物間の情報配置・参照関係等について、制作AIは、

`01_制作AI_判断・裁量基準.md`

の範囲内で自律判断する。

横断確認で問題を発見した場合でも、

**既存の承認済み教育設計・上位Source・成果物制作基準から正しい仕様を確定できる場合**

は、制作AIが自律的に修正する。

成果物間に差異が存在することだけを理由として、人間へ判断を委ねない。

------------------------------------------------------------------------

# 43. 制作AIの停止条件

以下の場合、制作AIは独自判断によって横断整合を成立させてはならない。

-   教育設計・上位Sourceから正しい教育仕様を確定できない
-   上位Source同士が矛盾している
-   必須／任意等の教育判断が不足している
-   知識深度を新たに決定する必要がある
-   問い・ワークの教育機能を新たに決定する必要がある
-   新しい教育内容が必要になる
-   新しいSession間導線が必要になる
-   Course単位で統一すべき構成方針が未決定であり、制作AIの裁量では確定できない
-   その他、制作AIの責任範囲を超える新しい判断が必要になる

この場合は、01に従って適切にエスカレーションする。

------------------------------------------------------------------------

# 44. 制作工程との境界

本文書は、

**成果物間整合・情報配置・変更同期の具体的な判定基準**

を定める。

一方、

-   いつ共通構造を作るか
-   いつ成果物別セルフレビューを行うか
-   いつ横断確認を行うか
-   いつ実ファイル確認を行うか
-   いつ独立監査へ提出するか

等の標準制作工程は、

`02_教材制作・品質保証フロー.md`

を正とする。

------------------------------------------------------------------------

# 45. 改善提案と現行教材を分離する

横断確認中に、

-   新しい教育内容
-   新しい補助資料
-   新しいSession参照
-   新しい学習導線
-   新しい運用方法
-   その他、現行教育設計・上位Sourceには存在しない改善可能性

を発見する場合がある。

これらは、

**現行教材の修正事項と混同しない。**

承認済み教育設計・上位Sourceに根拠がない事項は、現行教材へ実装せず、必要に応じて後続検討事項として分離して提案する。

提案が承認されるまで、現行教材の正式仕様として扱わない。

後続検討事項の具体的な蓄積・管理方法は、本文書では定めない。

------------------------------------------------------------------------

# 46. 本基準の非責任領域

本文書は、以下を直接設計しない。

-   Course固有の教育内容
-   Session固有の教育内容
-   学習目標
-   知識深度
-   問い・ワークそのもの
-   教育上の必須／任意
-   教育順序
-   感情設計
-   非変更領域
-   各成果物固有の制作仕様
-   制作AI全体の判断・裁量体系
-   教材制作全体の工程
-   出典の具体的管理方法
-   Version・Statusの具体的管理方法
-   教材識別の具体的管理方法
-   CHANGELOG運用
-   改善提案の恒久的な蓄積方法
-   Git等の技術的同期方法

これらは、それぞれの正式な責任資料を正とする。

------------------------------------------------------------------------

# 47. 本基準による横断整合の完成条件

以下を満たした場合、

**本基準上、教材一式の横断整合が成立している**

と判定する。

-   承認済み教育設計・上位Sourceおよび各成果物Missionに照らして、教材として実装・担保すべき情報が必要な成果物へ配置されている
-   必要情報が教材一式から欠落していない
-   各成果物が固有Missionを保持している
-   他成果物の責任を不必要に侵食していない
-   必要な重複に成果物固有の理由がある
-   成果物間で教育的意味が矛盾していない
-   必須／任意、知識深度、問い・ワークの教育機能等が保持されている
-   必要な対応・参照関係が正しく接続されている
-   変更による影響範囲が確認されている
-   影響する成果物が必要に応じて同期されている
-   古い情報・参照関係が残っていない
-   影響しない教育内容・成果物を不必要に変更していない
-   制作AIの責任範囲を超える事項を独自補完していない
-   必要な横断再確認が完了している

------------------------------------------------------------------------

# 48. 最終原則

成果物間整合とは、

> **すべての成果物を同じものにすることではない。**

PPT、受講者配布資料、ワークシート、講師進行表、講師実施設計、講師セルフチェックは、それぞれ異なるMissionを持つ。

したがって、教材一式として必要なのは、

**同じ文章、同じ情報量、同じ構造**

ではなく、

> **同じ承認済み教育を、それぞれの成果物が自分の責任で正しく実装し、必要なところでつながっていること**

である。

制作AIは、

**必要なものを落とさない。\
余計なものを増やさない。\
成果物ごとの役割を混ぜない。\
変更されたものだけを正しく波及させる。\
分からない教育判断を独自に埋めない。**

この状態を維持しながら、教材一式として一貫した教育実装を成立させる。
