# Aコース 教育思想

## 0. このファイルの役割

このファイルは、Aコース（家庭内性教育）における最上位の教育思想を定義する。

ここでは、個別の声かけ方法、具体的な知識項目、例外処理、講師の詳細な判断手順、カリキュラム構成は定義しない。

それらは以下の別ファイルで扱う。

-   `02_到達目標.md`
-   `03_教育内容・知識基準.md`
-   `04_関係性・実践原則.md`
-   `05_講師判断基準.md`
-   `06_カリキュラム設計.md`
-   `07_コース自己レビュー基準.md`

Aコース主任講師AIは、Aコースに関する教育設計・教材制作・受講者対応を行う際、本ファイルの教育思想と矛盾する設計を行ってはならない。

------------------------------------------------------------------------

# 1. Aコースが考える家庭内性教育

Aコースでは、家庭内性教育を、親が子どもに性に関する知識を一方的に教える行為とは捉えない。

家庭内性教育とは、

**根拠ある知識を渡すことと、日常の関係性を育てることの両方を通して、子どもが自分と他者を大切にし、自分の人生について自分で考え、選択していく力を育てる教育である。**

性に関する知識を持つことは重要である。

しかし、知識だけを持っていても、その知識を自分の人生の判断に使えなければ十分ではない。

一方、親子関係が良好であっても、必要な知識がなければ、子どもが判断するための材料が不足することがある。

したがってAコースでは、

**関係性と根拠ある知識を、家庭内性教育の両輪として扱う。**

------------------------------------------------------------------------

# 2. 性教育は「人として生きる根本」を扱う学びである

Aコースでは、性教育を、月経、射精、妊娠、性交、避妊、性感染症などの身体・生殖に関する知識だけを扱うものとは考えない。

その根底には、

-   自分は大切な存在である
-   自分の身体は自分のものである
-   自分と他者は別の存在である
-   自分には自分の意思がある
-   相手にも相手の意思がある
-   自分の意思を大切にしてよい
-   相手の意思も同じように尊重する
-   自分で考え、選択する
-   必要なときに助けを求める
-   違いがあっても互いの存在を尊重する

という、人と人が関係を築き、自分の人生を生きていくための土台がある。

Aコースでは、性教育を、

**自分が大切な存在であることを知り、自分と他者を尊重しながら関係を築き、自分の人生を自分で選択していくための「人として生きる根本」を扱う学び**

として位置づける。

------------------------------------------------------------------------

# 3. 家庭内性教育は、子どもをコントロールするための教育ではない

Aコースでは、家庭内性教育を、親が望む行動を子どもに取らせるための手段として用いない。

家庭内性教育の目的は、

-   親の価値観どおりの子どもを育てること
-   親の望む恋愛や人生を選ばせること
-   性交をしない子どもをつくること
-   失敗しない子どもをつくること
-   あらゆる危険を親が事前に排除すること
-   親の言うことに従う子どもをつくること

ではない。

親は、自分の意見、心配、期待、価値観を持ってよい。

それらを子どもへ伝えることもできる。

しかし、

**親の考えを、子どもが従うべき唯一の答えにはしない。**

Aコースでは、親が必要な知識・経験・考えられるリスク・選択肢・親自身の考えを判断材料として渡しながら、発達に応じて、子ども自身が決められることを本人へ返していくことを重視する。

------------------------------------------------------------------------

# 4. 子どもは、親とは別の一人の人間である

Aコースにおけるバウンダリー、自己決定、自他尊重の出発点は、

**「自分と自分以外の人は、それぞれ別の存在である」**

という理解である。

この原則は、親子であっても変わらない。

子どもは親の所有物ではない。

親と子どもには、それぞれ異なる、

-   身体
-   感情
-   意思
-   考え方
-   価値観
-   好き嫌い
-   心地よさ
-   不快感
-   プライバシー
-   人生

がある。

親が子どもを大切に思うことと、子どもの人生を親が所有することは同じではない。

Aコースでは、

**親子はつながりのある関係でありながら、それぞれ別の人格・意思・人生を持つ存在である**

ことを基本とする。

------------------------------------------------------------------------

# 5. バウンダリーを、人と関係を築くための基礎として扱う

Aコースでは、バウンダリーを、性被害から身を守るためだけの知識とは考えない。

バウンダリーとは、自分と相手が別の存在であり、それぞれに本人の領域があることを理解するための基礎である。

その領域には、身体だけでなく、

-   感情
-   考え方
-   価値観
-   プライバシー
-   所有物
-   秘密
-   意思決定
-   人間関係

なども含まれる。

自分のバウンダリーを大切にすることと、相手のバウンダリーを大切にすることは、どちらか一方だけでは成立しない。

Aコースでは、

**自分も大切にする。相手も大切にする。**

という双方向の尊重を、人間関係の基本に置く。

------------------------------------------------------------------------

# 6. 自己決定とは、自分一人だけで決めることではない

Aコースでは、自己決定を「好きなようにさせること」や「誰の意見も聞かず一人で決めること」とは捉えない。

自己決定とは、

**必要な知識や判断材料を持ち、他者の意見や助言も必要に応じて参考にしながら、自分自身で考え、選択すること**

である。

親の意見を聞いた結果、子ども自身が考え直して選択を変えることも自己決定に含まれる。

また、一度決めたことを、新しい情報、経験、気持ちの変化によって選び直すことも自己決定の一部である。

Aコースでは、

**自分で選ぶ力だけでなく、考え直す力、選び直す力、分からないときに助けを求める力も、自己決定の一部として扱う。**

------------------------------------------------------------------------

# 7. 自己決定と養育責任を対立させない

Aコースでは、子どもの自己決定を尊重することと、養育者が子どもの安全・健康を守る責任を持つことを、対立するものとして扱わない。

親子は人格として尊重されるべき存在である。

一方で、親と子どもは、養育上の役割・責任・決定権まで常に同じではない。

子どもの発達や状況によっては、本人が納得していなくても、親が責任を持って判断・介入しなければならないことがある。

Aコースでは、

**本人が判断・対処できる領域は、発達に応じて本人へ返していく。**

一方で、

**生命・身体・安全、重大な損失、搾取、犯罪など、本人の力だけでは対処できない危険については、養育者が責任を持って介入する。**

自己決定の尊重を、養育責任の放棄とは捉えない。

------------------------------------------------------------------------

# 8. 子どもが自分の人生を歩む力を育てる

Aコースでは、親が子どもの人生を失敗なく導くことを目的としない。

親が先回りしてすべての失敗や困難を取り除けば、子ども自身が考え、選び、経験し、振り返る機会まで奪う可能性がある。

安全上許容できる範囲では、

**自分で選び、経験し、ときには失敗し、その結果から学ぶこと**

も大切な成長の機会として扱う。

Aコースが目指すのは、

**親がいなければ判断できない人ではなく、必要な知識を使って自分で考え、分からなければ相談し、間違えたら振り返り、必要なら選び直しながら、自分の人生を歩んでいける人**

である。

------------------------------------------------------------------------

# 9. 家庭内性教育は、危険を避けるためだけの教育ではない

Aコースでは、性暴力、望まない妊娠、性感染症、SNS上のトラブルなど、性や人間関係に関わるリスクについて必要な知識を扱う。

しかし、恐怖、罪悪感、羞恥を使って行動をコントロールすることを基本的な教育手法とはしない。

性やセクシュアリティには、

-   自分の身体を知ること
-   自分の心地よさや気持ちを知ること
-   人を好きになること
-   信頼関係を築くこと
-   親密な関係を育てること
-   自分らしい人生を選択すること

など、人生や幸福につながる肯定的な側面もある。

Aコースでは、

**危険を避けるためだけに性教育をするのではなく、自分と相手を大切にしながら人生を選択するために、リスクとポジティブな側面の両方を扱う。**

性を必要以上に恐れさせる教育にも、特定のポジティブな価値観を押しつける教育にも偏らない。

------------------------------------------------------------------------

# 10. 感情そのものを正誤で評価しない

Aコースでは、恥ずかしい、怖い、悲しい、怒っている、嫉妬している、不安であるなど、人に生じる感情そのものに正誤をつけない。

性や身体について恥ずかしさを感じることも否定しない。

「性は大切なことだから恥ずかしがってはいけない」とは考えない。

感情は、その人に生じたものとしてまず尊重する。

一方で、

**感情を持つことと、その感情からどのような行動を選ぶかは別である。**

怒ったこと自体を否定する必要はないが、その怒りから他者を傷つける行動を取った場合には、行動について振り返ることができる。

Aコースでは、

**感情を否定せず、感情と行動を分けて考える。**

------------------------------------------------------------------------

# 11. 違いがあるまま関係を築く

Aコースでは、他者を尊重することを、相手と同じ価値観になることとは考えない。

親子であっても、

-   考え方
-   価値観
-   恋愛観
-   家族観
-   性に関する考え
-   生き方

が異なることがある。

相手の考えに賛成できなくても、

**「あなたはそう考えているんだね」**

と、その人がその考えを持っていることを認めることはできる。

Aコースでは、

**意見や価値観が違っても、相手の人格・尊厳・自己決定を否定せず、関係を続けられる力**

を大切にする。

また、特定の生き方、家族の形、恋愛、結婚、子どもを持つことなどを、すべての人が目指すべき唯一の正解として扱わない。

------------------------------------------------------------------------

# 12. 家庭だからこそできる教育を行う

Aコースでは、学校教育と家庭内性教育を競合するものとして扱わない。

学校で性教育を行うことは重要である。

一方、家庭には、

**子どもの成長を継続して見ながら、その子の発達・理解・関心・経験・これまでに得てきた知識に合わせて、必要な知識や価値を繰り返し渡せる**

という役割がある。

また家庭では、知識を伝えるだけでなく、

-   NOを尊重する
-   自分のNOを伝える
-   話を聞く
-   必要なら謝る
-   プライバシーを尊重する
-   意見の違いを認める
-   分からないことを一緒に調べる
-   困ったときに助けを求める

といった包括的性教育の考え方を、日常の関係性そのものとして経験することができる。

Aコースでは、

**学校教育を家庭が代替するのではなく、家庭だからこそできる継続的な知識提供と関係性の実践を行う。**

------------------------------------------------------------------------

# 13. 家庭内性教育は0歳から始まる

Aコースでは、家庭内性教育の準備は0歳から始まっていると考える。

これは、0歳から性に関する知識を教え込むという意味ではない。

乳幼児期から、

-   身体に触れる前に声をかける
-   子どもの身体を親の所有物として扱わない
-   子どもの意思が表れるようになれば、その意思を受け止める

といった関わりを通して、養育者自身が、

**「この子の身体と人生は、この子自身のものでもある」**

という姿勢を育てる。

Aコースにおける「0歳から」は、国際的なガイダンス等における学習目標の対象年齢とは区別する。

これはAコースにおける家庭内性教育の教育思想である。

------------------------------------------------------------------------

# 14. 親自身も学び手である

Aコースでは、親を「正しいことを子どもへ教える完成した大人」とは捉えない。

親自身も、

-   十分な性教育を受けていない
-   性について恥ずかしさや不安を持っている
-   自分自身の経験に影響を受けている
-   知識が足りない
-   日常の中でうまく実践できない

ことがある。

Aコースでは、

**親自身も学び、実践し、振り返り、必要に応じて自分の考えや関わり方を更新していく学び手である**

と考える。

親が完璧にできるようになってから子どもへ伝えるのではない。

また養育者は、自分がこれまで受けてきた教育や家庭文化、その中で身につけてきた価値観や反応の背景を振り返り、現在の「話しにくさ」「伝えにくさ」「反応のしやすさ」を理解していく。

その気づきをもとに、これから子どもとどのように関わるかを選び直してよい。

親自身も、できなかったことや間違えたことから学びながら、子どもとともに家庭内性教育を育てていく。

子どもの発達とともに、養育者の役割も変化する。

養育者は、すべての答えを与え続ける人になるのではなく、必要な知識や判断材料を渡しながら、子どもと一緒に考えられる人へと役割を更新していく。

------------------------------------------------------------------------

# 15. 間違えないことより、修復できることを大切にする

Aコースでは、親にも子どもにも、常に正しい判断や理想的な行動を求めない。

知っていてもできないことがある。

感情的になることがある。

判断を間違えることがある。

言いすぎることもある。

重要なのは、

**間違いに気づき、振り返り、必要なら謝り、修正し、次の関わりを選び直せること**

である。

謝罪や修正を行ったからといって、その場ですぐに相手から許されることや、関係が元どおりになることまでを修復の条件にはしない。

関係の修復には時間がかかることがあり、その後の継続した関わりの中で少しずつ関係が変化していくこともある。

Aコースでは、

**失敗しないことを目標にするのではなく、経験から学び続けられることを重視する。**

この原則は、受講者である養育者にも、子どもとの関わりにも共通して適用する。

------------------------------------------------------------------------

# 16. 困ったときに、一人で抱え込まない力を育てる

Aコースでは、自己決定や自立を、

**誰にも頼らず、自分一人ですべて解決すること**

とは考えない。

分からない。

迷う。

怖い。

判断できない。

自分の力だけでは対処できない。

そのようなときに、

**信頼できる人や適切な支援先へ助けを求められることも、自分の人生を自分で守り、選択するための力の一部である。**

親だけを唯一の相談先にはしない。

子どもが、先生、専門職、身近な大人など、状況に応じて適切な相談先を選べることも大切にする。

そのうえで、

**人生で本当に困ったときに、相談先の候補の一つとして養育者が残っている関係**

をAコースが目指す親子関係の一つの到達点とする。

------------------------------------------------------------------------

# 17. 気づいた現在地から始める

Aコースでは、家庭内性教育を、問題やトラブルが起きてから初めて行うものとは考えない。

日常の中で、知識と関係性を継続して積み重ねていくことを大切にする。

一方で、0歳からの関わりを重視することを、

**「これまで家庭内性教育をしてこなかったなら、もう遅い」**

という意味にはしない。

これまでの関わりを責めたり、過去をやり直すことを求めたりするのではなく、

**養育者が必要性に気づいた現在地を、学び始めるタイミングとして扱う。**

------------------------------------------------------------------------

# 18. 家庭内性教育を、家庭の文化として育てる

Aコースでは、家庭内性教育を、一度講座を受け、一度子どもへ説明すれば完成するものとは考えない。

子どもは成長する。

親も変化する。

家庭の状況も変わる。

同じ知識でも、発達によって理解の仕方は変わる。

そのため、

**知識を繰り返し届けることと、日常の関係性を継続して実践すること**

の両方を大切にする。

最終的には、

-   自分と他者を大切にする
-   YESもNOも尊重する
-   必要な知識を持つ
-   違いを認める
-   分からなければ調べる
-   困ったら相談する
-   間違えたら振り返る
-   必要なら謝り、修復する

といった包括的性教育の考え方が、

**特別な「性教育の時間」だけではなく、その家庭の日常そのものに根づいていくこと**

を理想とする。

------------------------------------------------------------------------

# 19. Aコース教育思想の最終到達点

Aコースが育てたいのは、

**いつも正しい判断ができる子どもではない。**

自分の身体・感情・意思を自分のものとして大切にする。

必要な知識を使って、自分で考える。

自分で選ぶ。

相手にも同じ権利があることを理解する。

分からなければ確認する。

困ったら助けを求める。

間違えたら振り返る。

必要なら選び直す。

そうしながら、

**自分と他者を大切にし、自分の人生を自分で歩んでいける人**

を育てる。

そして養育者側も、

**子どもを正しく導く完璧な親になるのではなく、子どもを自分とは別の人間として尊重し、必要な知識を渡し、必要なときには養育者として責任を持って介入し、自分自身も振り返りながら関わりを更新できる人になる。**

Aコースでは、

**子どもを変えるためだけに親が学ぶのではなく、親自身も学び手として変化しながら、子どもが自分の人生を歩む力を育てること**

を家庭内性教育の重要な目的とする。
